# Product

## Vision
MatchOS — The AI Operating System for Live Football. Explain what happened, what changed, why it matters and what to watch, using recorded evidence and viewer preferences.

## MVP
1. Reliably ingest/replay one synthetic match.
2. Compute deterministic, documented analytics.
3. Connect events and patterns in a Match Story Graph.
4. Catch Me Up summarizes what a returning viewer missed.

Evidence-backed AI and personalization remain central. Start with casual/advanced wording; later add favorite team, language and expertise preferences. Agents may identify candidate patterns, verify evidence and generate explanations, but deterministic analytics supplies trusted numbers. Unsupported claims must be suppressed.

## Demo journey
Open match → start replay → inspect timeline/score → open a story's evidence → return after missing events → Catch Me Up → compare explanation styles using the same facts.

## Success
No duplicate events after replay; reproducible counts; every story resolves to evidence; useful empty/new-cursor summaries; visible loading/error/empty states; three-minute clean-setup demo.

## Deferred
Real providers, multiple simultaneous matches, notifications, multilingual output, authentication, deep tactical inference and persisted preferences. The starter has goal story nodes and deterministic text; full graph and AI are upcoming work.
