# Targeted shot-list scope correction — 24 October 2026

The v19 Casual revision correctly said that Mbeumo had two saved shots at 16:40 and 18:40. It already placed the full three-pass contribution in its verified 15:00–25:00 window. The validator nevertheless required another rolling window on the sentence listing those two exact events. This was a false rejection, preserved in `backend/tests/fixtures/v19-enumerated-shot-rejection.json`.

The new exception recognizes a narrow English/Spanish construction with an explicit named shooter, count, outcome and list of shot clocks. It verifies each distinct event against the **cited** creator chronology. A goal-producing shot cannot count as saved; repeating one clock cannot count as two shots; a passer cannot inherit the recipient's shots. Wrong recognized lists are rejected even when a correct rolling window is also present. The exception does not supply scope to extra pass counts, unrelated numbers or a competing window. The selected contribution still needs its own measured window elsewhere in the paragraph.

This accepts or rejects the whole AI paragraph. It does not insert commentary or rewrite the model's wording. It is not a general natural-language parser; unrecognized constructions retain the existing scope checks and fallible model review.
